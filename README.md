# نموذج منصة اللغة العربية

هذا نموذج أولي مستقل لتجربة تصميم منصة تعلم مصغّر لمادة اللغة العربية – ثالث متوسط.

## الفكرة
- كل درس مقسم إلى أهداف واضحة.
- كل هدف/نقطة يشرح باختصار.
- بعد كل نقطة تدريب فوري.
- فيديو قصير يمكن تضمينه من منصة خارجية.
- اختبار إتقان في نهاية الدرس.
- إذا أخطأ الطالب، يعود فقط إلى النقطة التي لم يتقنها.
- مسار معالجة ومسار إثرائي بدل إعادة الدرس كاملًا.

## الملفات
- `index.html`: واجهة النموذج.
- `styles.css`: التصميم المتجاوب RTL.
- `app.js`: تفاعلات النموذج.
- `supabase_schema.sql`: مخطط قاعدة البيانات المقترح لمشروع Supabase مستقل.

## التشغيل
افتح `index.html` في المتصفح مباشرة.

## ملاحظة
هذا النموذج غير متصل بقاعدة بيانات حقيقية بعد. عند ربط حساب GitHub الجديد ومشروع Supabase الجديد يمكن تحويله إلى نسخة فعلية وحفظ الطلاب والنتائج والتقدم.
