# معمارية التنفيذ المباشر في منصة تمكّن

## الهدف

تحويل الأوامر الإدارية الواضحة إلى إجراءات فعلية على منصة تمكّن دون مرحلة وسيطة للاكتفاء بالتوصية أو حفظ الطلب فقط.

## المكونات

1. **واجهة المعلم – مركز الأوامر**
   - المسار: `teacher-app.html`
   - المنطق: `command-console.js`
   - يستقبل أمرًا عربيًا مختصرًا ويعرض النتيجة وسجل العمليات.

2. **منفّذ الأوامر الخلفي**
   - المصدر: `supabase/functions/tamakkun-command/index.ts`
   - منشور كـ Supabase Edge Function باسم `tamakkun-command`.
   - لا يقبل إلا جلسة معلم أو مدير فعالة.
   - يحول اللغة العربية إلى أوامر داخل قائمة مسموحة Allowlist.

3. **قاعدة البيانات**
   - `command_jobs`: سجل العملية وحالتها والنتيجة ولقطة ما قبل التعديل.
   - `command_events`: سجل تفصيلي زمني.
   - `student_interventions`: التدخلات العلاجية والإثرائية المسندة للطلاب.

4. **واجهة الطالب**
   - فتح الدرس يتحقق من الخادم عبر `lesson_access`.
   - إغلاق درس من مركز الأوامر يمنع الطالب من فتحه فعليًا، وليس مجرد تغيير بصري.

## دورة التنفيذ

```text
أمر المعلم
  ↓
التحقق من الجلسة والدور
  ↓
تحليل الأمر إلى نوع + بيانات
  ↓
التحقق من Allowlist والقيم
  ↓
إنشاء command_job بمفتاح idempotency
  ↓
تنفيذ العملية في قاعدة البيانات
  ↓
حفظ النتيجة + before_snapshot
  ↓
إظهار النتيجة للمعلم
  ↓
إتاحة التراجع للعمليات المدعومة
```

## الأوامر المدعومة في الإصدار الأول

- `افتح درس الحال`
- `أغلق درس HAL-01`
- `غيّر الإتقان لدرس الحال إلى 85`
- `عطّل الطالب S3A001`
- `فعّل الطالب S3A001`
- `سجل خروج الطالب S3A001`
- `أسند علاج درس الحال للطالب S3A001`
- `أسند إثراء درس الحال للطالب S3A001`
- `اختبر النظام`

## ضوابط الأمان

- لا يوجد تنفيذ Shell أو SQL حر من واجهة المستخدم.
- لا توجد أوامر حذف عامة أو أوامر نصية غير مقيدة.
- السماح للمعلم/المدير فقط.
- التحقق من الدرس والطالب قبل التعديل.
- Idempotency لمنع تكرار الأمر عند إعادة الإرسال.
- Audit log لكل أمر.
- التراجع مدعوم في العمليات القابلة للعكس.
- إبطال جلسات الطالب تلقائيًا عند تعطيل حسابه.
- أسرار Supabase تبقى على الخادم ولا توجد في الواجهة.

## سياسة الفشل

- خطأ في صيغة الأمر: لا ينفذ شيء ويظهر `unrecognized_command`.
- درس غير موجود: `lesson_not_found`.
- اسم درس ملتبس: `lesson_ambiguous`.
- طالب غير موجود: `student_not_found`.
- حد إتقان غير صالح: `invalid_mastery_threshold`.
- أي فشل يسجل في `command_jobs` و`command_events`.

## التراجع

مدعوم حاليًا لـ:
- فتح/إغلاق الدرس.
- تغيير حد الإتقان.
- تفعيل/تعطيل الطالب.
- إسناد تدخل تعليمي، ويصبح التدخل `cancelled`.

لا يدعم التراجع عن إبطال الجلسات لأن الجلسة المحذوفة لا يمكن استعادتها بأمان.

## CI/CD

- `.github/workflows/quality.yml`: بوابة جودة على كل Pull Request وعلى `main`.
- `.github/workflows/pages.yml`: نشر الواجهة تلقائيًا إلى GitHub Pages بعد الدمج في `main`.
- مصدر Edge Functions محفوظ داخل المستودع، والنشر الحالي تم مباشرة إلى مشروع Supabase المتصل.
