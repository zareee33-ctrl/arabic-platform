# تحديث واجهات تمكّن — 9 أكتوبر 2026

## التغيير
إعادة تنظيم الرئيسية وبوابتي الطالب والمعلم بتصميم عربي متجاوب مستوحى من تنظيم حصاد العلم، مع الحفاظ على هوية تمكّن ومحتواها الفعلي. أُضيفت طبقة تصميم مشتركة للوحات الطالب والمعلم، وبطاقات وصول مباشر للكتاب والأعمال وملف الإنجاز والنتائج، وتحكم بإظهار كلمة المرور. أصبحت قائمة الطالب على الجوال قابلة للإغلاق بلوحة المفاتيح والخلفية، ودائرة الإتقان تتبع النسبة المعروضة فعليًا.

## نطاق التحقق
- مراجعة صور الصفحات العامة الثلاث ولوحتي الطالب والمعلم بعرضي 1440 و390 بكسل: دون تجاوز عرض الشاشة.
- اختبار الدخول الناجح والفاشل، إعادة تفعيل زر الدخول بعد الفشل، إظهار وإخفاء كلمة المرور، ومسارات التنقل.
- اختبار قائمة الطالب على الجوال واختصارات الأقسام ودائرة الإتقان عند 0% و75%.
- مقارنة معالجات الدخول ومعرّفات الحقول بالأصل؛ بقيت كما هي.
- نجاح scripts/verify-static.mjs وفحص صياغة JavaScript وفحص git diff --check.

اختبارات الدخول واللوحات استخدمت استجابات API محاكاة محلية واعترضت جميع الطلبات الخارجية إلى قاعدة البيانات. لا تمثل تحققًا من صحة بيانات دخول حساب حقيقي أو من توفر الخادم، ولم تُكتب بيانات طلاب أو نتائج. ملفات API وقاعدة البيانات ومنطق التصحيح لم تتغير.
