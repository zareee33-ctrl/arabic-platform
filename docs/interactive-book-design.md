# تصميم الكتاب التفاعلي – منصة تمكّن

## النطاق
تم تحويل كتاب **لغتي الخالدة – الصف الثالث المتوسط – الفصل الدراسي الأول** إلى كتالوج تعلم تفاعلي يغطي وحدتي:
- حقوق وواجبات.
- أعلام معاصرون.

## بنية الدرس
كل درس يمر بأربع مراحل إلزامية:
1. تشخيص قصير.
2. نشاط تفاعلي.
3. تحقق من الإتقان.
4. تثبيت: إثراء عند النجاح أو دعم موجّه عند الحاجة.

## أنواع التفاعل
- تصنيف.
- ترتيب خطوات.
- بناء جملة.
- تدريب خط بصري.
- تسجيل صوتي.
- أسئلة تشخيص وتحقق.
- انعكاس كتابي قصير.

## التكيف
لا يعتمد القرار على نمط تعلم ثابت. يعتمد على:
- الإجابة التشخيصية.
- نتيجة النشاط.
- نتيجة تحقق الإتقان.
- سجل التفاعل.
- الحاجة إلى الدعم أو الإثراء.

## خريطة الوحدات
### الوحدة الأولى: حقوق وواجبات
بوابة الوحدة → المدخل → الاستماع → وقضى ربك → حقوق الأشخاص ذوي الإعاقة → دَيْن الكريم → الألف اللينة في الأفعال الثلاثية → رسم (ل، لا) → اسم الفاعل → القسم → الحال → العصف الذهني → كتابة خطبة محفلية → إلقاء خطبة → حقوق المرضى → نموذج الاختبار.

### الوحدة الثانية: أعلام معاصرون
بوابة الوحدة → المدخل → حمد الجاسر علامة الجزيرة → سلمان بن عبد العزيز ملك الحزم والعزم → قافية الحياة → الجبل الأشم → الألف اللينة في الأفعال غير الثلاثية → رسم (ك، م) → اسم المفعول → الشرط → التمييز → التخطيط للموضوع → كتابة سير غيرية → عرض الرأي → بين الإبداع والاجتهاد → نموذج الاختبار.

## التتبع
يسجل النظام أحداثًا من نوع:
- lesson_open
- diagnostic_answer
- activity_complete
- mastery_answer
- lesson_mastered
- lesson_support_needed
- lesson_close

كل حدث يرتبط بالطالب والدرس والوقت ونوع التفاعل والدرجة وبيانات إضافية JSON.

## التقارير
لوحة المعلم تعرض لكل درس:
- عدد مرات البدء.
- عدد الأنشطة المنفذة.
- عدد حالات الإتقان.
- عدد حالات الحاجة إلى الدعم.
- متوسط الدرجات المسجلة.
- عدد الطلاب المتفاعلين.

## معايير الإتقان
الإصدار الأول يستخدم تحققًا صريحًا في نهاية الدرس. النتيجة تحفظ في تقدم الطالب، ويمنع اعتبار الدرس متقنًا إذا فشل سؤال التحقق النهائي.

## الوصول
التصميم Mobile-first ويدعم:
- الهاتف.
- اللوحي.
- الحاسوب.
- حجم نص واضح.
- عدم الاعتماد على اللون وحده.
- أزرار كبيرة نسبيًا.
- بدائل نصية للتعليمات.
