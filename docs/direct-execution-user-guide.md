# دليل استخدام مركز الأوامر

## الوصول

1. سجل الدخول بحساب المعلم.
2. افتح **مركز الأوامر** من القائمة.
3. اكتب أمرًا من الصيغ المدعومة.
4. اضغط **تنفيذ الآن**.
5. راجع الحالة ورقم العملية والنتيجة.
6. راجع **سجل التدقيق** للتأكد من التنفيذ.

## أمثلة

### فتح درس
```text
افتح درس الحال
```

### إغلاق درس
```text
أغلق درس HAL-01
```

### تغيير حد الإتقان
```text
غيّر الإتقان لدرس الحال إلى 85
```

### تعطيل طالب
```text
عطّل الطالب S3A001
```

### إسناد علاج
```text
أسند علاج درس الحال للطالب S3A001
```

## سجل التنفيذ

كل عملية تعرض:
- حالة التنفيذ.
- نوع العملية.
- رقم العملية.
- النتيجة.
- وقت التنفيذ.

## التراجع

إذا كانت العملية قابلة للتراجع يظهر زر **تراجع** في سجل العمليات.

لا تستخدم التراجع بدل المراجعة؛ هو وسيلة استرداد من خطأ تشغيلي فقط.

## قواعد كتابة الأمر

- استخدم رمز الطالب كما هو.
- استخدم اسم درس واضحًا أو كوده.
- لا تضع كلمات مرور في الأوامر.
- لا تضع بيانات حساسة أو أرقام هوية.
- لا تكتب أوامر SQL أو أوامر نظام؛ النظام لن يقبلها.

## الصيانة

- راجع سجل `command_jobs` عند وجود شكوى.
- راجع `command_events` لمعرفة تسلسل العملية.
- لا توسع قائمة الأوامر قبل إضافة تحقق وصلاحيات واختبارات لكل أمر جديد.
