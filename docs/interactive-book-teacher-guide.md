# دليل المعلم – الكتاب التفاعلي

## كيف يبدأ الطالب؟
1. يسجل الطالب الدخول.
2. يفتح **كتابي التفاعلي**.
3. يختار الوحدة والدرس.
4. يبدأ التشخيص.
5. ينفذ النشاط التفاعلي.
6. يجيب عن تحقق الإتقان.
7. يحصل على إثراء أو دعم موجّه.
8. تحفظ النتيجة في حسابه.

## كيف أتابع الطلاب؟
من **المستوى والتقدم** في لوحة المعلم:
- راقب نتائج المعرفة والتطبيق والاستدلال.
- راقب قسم **تحليلات التفاعل داخل الدروس**.
- إذا كان عدد حالات الدعم أكبر من الإتقان في درس محدد، راجع نشاط ذلك الدرس.
- افتح ملف الطالب لمعرفة تقدمه على مستوى الدروس.

## متى أسند دعمًا إضافيًا؟
- عند تكرار lesson_support_needed.
- عند انخفاض الاستدلال مع بقاء المعرفة مرتفعة.
- عند بدء الدرس أكثر من مرة دون إتقان.
- عند كثرة التوقف قبل النشاط النهائي.

## كيف أحدث محتوى درس؟
1. افتح book-course-data.js.
2. عدّل هدف الدرس أو سؤال التشخيص أو النشاط أو التحقق.
3. لا تغيّر code الخاص بالدرس بعد استخدامه مع الطلاب.
4. ارفع content_version عند تغيير بنية الدرس.
5. مرر التعديل عبر Quality Gate قبل النشر.

## قواعد المحتوى
- لا تعرض فقرة طويلة دون تفاعل.
- اجعل كل شاشة ذات مهمة واحدة.
- لا تكرر السؤال نفسه كعلاج.
- العلاج يستهدف المهارة المتعثرة.
- الإثراء يرفع مستوى التفكير، لا يكرر السهل.
